# 2026 Macro Plan

Three-phase year: B-race (half) → A-race (STP) → A-race (Marathon). Phase transitions are the highest-risk points and get deliberate de-load treatment.

Review cadence: every 3–4 weeks, or after any disrupted week.

### Working preferences (for any chat using these files)

- **Attempt over settle.** On A-race goals Joseph would rather attempt the full thing and stop if it breaks (sharp pain, real injury) than downgrade the goal in advance — one-day STP (7/11/26), full marathon run the whole way (10/7/26). Don't default to distance downgrades or planned walking as the fallback; frame contingencies around the stop condition, not around shrinking the goal.
- **Approximate data is fine.** Don't chase exact numbers from past sessions. Mark gaps `[not recorded]` and flag reconstructed figures as approximate rather than carrying them as open questions; only ask for a missing value if it changes a decision going forward.
- **Loose structure (from 10/7/26).** Work is busy — plan week to week and adapt on the fly; the long run is the protected session.

## Phase 2 — STP Recovery + Transition (Jul 13 – Jul 26, 2 weeks)

- Marathon build start 7/27 is conditional on a clean recovery fortnight — if RHR/HRV haven't normalized or running restart shows any gait compensation, slide the start a week. 18 weeks has slack; the risk window doesn't.

- **Week 1:** very easy. Short walks, light spins. No running days 1–3. First run gated on: RHR back within 2–3 bpm of the 55–60 baseline, no lingering leg soreness on stairs/walks, left knee quiet in daily life. Target ~Thu 7/16–Sat 7/18, 20–25 min at HR cap, walk breaks freely allowed.
- **Week 2:** rebuild run volume cautiously. 3 short easy runs (20–35 min), no long run, no strides yet. Assess body feedback daily — any gait asymmetry or knee signal ends the run immediately. This is the highest-risk injury period of the year — 10 weeks of bike-dominant stress, then reintroducing ground reaction forces.
- **PT eval for left knee: book this fortnight** — before run volume ramps, not after the next flare.
